# SAMAR Laptop Choice Portal

A modern, responsive web application for finding the best laptop based on budget, storage, RAM, processor generation (Intel 11th, 12th, 13th, 14th Gen & AMD Ryzen), brand, GTA 5 FPS gaming benchmarks, and intended purpose.

## What's Included

1. **GTA 5 Benchmark FPS**:
   - Exact tested GTA 5 FPS displayed on every laptop card (e.g. 92 FPS, 110 FPS, 135 FPS, 165+ FPS).
   - Dedicated GTA 5 FPS gauge and test settings in the Details Modal.
   - GTA 5 FPS comparison row in the Side-by-Side Compare Table.
   - Dedicated "Sort by GTA 5 FPS (Highest First)" sorting option.
2. **Intel 11th, 12th, 13th & 14th Gen**:
   - Intel 11th Gen Tiger Lake (i3-1115G4, i5-11400H, i7-11800H).
   - Intel 12th Gen Alder Lake (i3-1215U 6-core, i5-12450H, i5-12500H 12-core, i7-12650H 10-core).
   - Intel 13th Gen Raptor Lake (i3-1305U, i3-1315U, i5-13420H, i5-13500H 12-core, i5-13450HX, i7-13620H, i7-13650HX 14-core).
   - Intel 14th Gen Raptor Lake Refresh / Ultra (i5-14450HX, i7-14700HX 20-core, Core Ultra 7 155H 16-core).
   - Full AMD Ryzen Series (Ryzen 3, Ryzen 5 5500U/7520U, Ryzen 7 7735HS/7840HS/8845HS) & Apple M3.
3. **Original Model Photos**:
   - Authentic, high-resolution product photos matching real laptop hardware models.
4. **SAMAR Recommendation Algorithm**:
   - Dynamic 0 - 100% Match scoring.
   - Spotlight on SAMAR's #1 laptop.
   - Side-by-side comparison up to 3 laptops.

## How to Run

1. Open `index.html` directly in any web browser.
2. Or run:
   ```bash
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080` in your web browser.
